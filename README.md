# سیستەمی بەڕێوەبردنی موڵکەکانی RASEL REAL ESTATE

سیستەمێکی وێبی پیشەیی و سەردەمییە بۆ تۆمارکردن، بەڕێوەبردن، بەدواداچوونی دارایی و نەخشەی موڵکەکان (خانوو، شوقە، ڤیلا، دوکان، ئۆفیس، زەوی بازرگانی و وەبەرهێنان).

دیزاینکراوە بە تایبەتی بۆ کارکردن لەسەر کۆمپیوتەر و مۆبایل، بە ڕووکارێکی لوکس (Luxury Real Estate Dark/Gold Theme) و تەواو سۆرانی (RTL).

---

## تایبەتمەندییە سەرەکییەکان

### ١. پاراستنی سیستەم و چوونەژوورەوەی تایبەت
- سیستەمەکە بە شێوەیەکی بنەڕەتی قفڵکراوە و تەنها بە **وشەی نهێنی (PIN / Password)** دەکرێتەوە.
- وشەی نهێنی سەرەتایی: **`Ibo0909`** (دەتوانیت لە ڕێکخستنەکان بیگۆڕیت بۆ هەر وشەیەکی تر).
- بژاردەی &quot;بمپارێزە لەسەر ئەم ئامێرە&quot; تا پێویست نەکات هەموو جارێک وشەی نهێنی بنووسیتەوە.

### ٢. داشبۆرد و ئامارە سەرەکییەکان
- **کۆی موڵکەکان**: ژمارەی هەموو موڵکەکان لەگەڵ دابەشبوونیان بەپێی جۆر (ڤیلا، شوقە، خانوو، زەوی).
- **موڵکی بەردەست**: ڕێژەی موڵکە ئامادەکان بۆ فرۆشتن یان کرێ.
- **داهاتی کرێ**: کۆی داهاتی مانگانەی مسۆگەرکراو لە یەکە بەکرێدراوەکان بە دۆلار ($) و دینار.
- **قازانج و خەرجی**: شیکاری وردی قازانجی پوخت، خەرجی چاککردنەوە و کۆی بەهای سەرمایەی موڵکەکان.

### ٣. بەڕێوەبردنی موڵکەکان (موڵکەکانم)
- تۆمارکردنی خانوو، شوقە، ڤیلا، دوکان، ئۆفیس، زەوی بازرگانی و کشتوکاڵی، بینا.
- فلتەری خێرا بەپێی: جۆری موڵک، مەبەست (فرۆشتن / کرێ / وەبەرهێنان)، بارودۆخ (بەردەست، بەکرێدراو، فرۆشراو)، و شار (هەولێر، سلێمانی، دهۆک، هتد).
- گەڕانی پێشکەوتوو بەپێی ناونیشان یان کۆدی نهێنی موڵک (نموونە: `RSL-101`).
- وێنە و بەڵگەنامە: بارکردنی چەندین وێنە لە مۆبایل و کۆمپیوتەر یان دانانی بەستەری وێنەکان.
- بەشی زانیاری نهێنی خاوەن موڵک (پەیوەندی، تێبینی نهێنی).

### ٤. نەخشەی ڕاستەوخۆ (Interactive OpenStreetMap)
- بینینی هەموو موڵکەکان لەسەر نەخشەی کوردستان و عێراق بە مارکەری ڕەنگاوڕەنگ.
- پیشاندانی کارتی زانیاری خێرا (وێنە، نرخ، کۆد) لەگەڵ دوگمەی بینینی تەواوەتی.
- دیاریکردنی شوێنی موڵکی نوێ بە تەنها کلیکێک لەسەر نەخشە و کۆپیکردنی پۆوتانی GPS.

### ٥. فرۆشتن و کرێ و گرێبەستەکان
- تۆمارکردنی ناوی کڕیار یان کرێچی، ژمارەی مۆبایل، ناسنامە، بەرواری دەستپێک و کۆتایی.
- بەدواداچوونی پارەی وەرگیراو و پارەی ماوە.
- گۆڕینی ئۆتۆماتیکی دۆخی موڵکەکە بۆ &quot;بەکرێدراو&quot; یان &quot;فرۆشراو&quot; لە کاتی پاشەکەوتکردندا.

### ٦. ژمێریاری و وەبەرهێنان
- تۆمارکردنی هەموو داهاتەکان (کرێ، کۆمیسیۆن) و خەرجییەکان (چاککردنەوە، نۆژەنکردنەوە، باج، ڕیکلام).
- بەستنەوەی خەرجی بە موڵکێکی دیاریکراو یان خەرجی گشتی ئۆفیس.
- پیشاندانی پوختەی قازانج و دەرچوونەکان.

### ٧. پاشەکەوت و گەڕاندنەوەی داتا (Backup & Restore)
- دەرکردنی فایلی پاشەکەوتی تەواوی سیستەم (Download JSON Backup) بە یەک کلیک.
- گەڕاندنەوەی داتاکان لە هەر کاتێکدا لە ڕێگەی فایلی پاشەکەوتەوە.

## چۆنیەتی دەستپێکردن و بەکارهێنان

### ١. بەکارهێنانی خێرا (Local Mode):
تەنها پەڕگەی `START_RASEL.bat` لە فۆڵدەری سەرەکی پڕۆژەکەدا بکەرەوە. سیستەمەکە ڕاستەوخۆ وێبئەپەکە دەستپێدەکات و لە وێبگەڕەکەتدا بەستەری دەبێتەوە:
```bash
http://localhost:3000
```

### ٢. بەستنەوە بە داتابەیسی هەوری (Supabase / PostgreSQL):
1. بچۆ [supabase.com](https://supabase.com) و پرۆژەیەکی نوێ دروست بکە.
2. بچۆ بەشی **SQL Editor**، ناوەڕۆکی فایلی `supabase/schema.sql` لەوێ پەست بکە و Run دابگرە.
3. فایلی `.env.local.example` لە پرۆژەکەدا بگۆڕە بۆ `.env.local` و زانیارییەکانی `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` پڕبکەرەوە.

## تەکنەلۆژیا بەکارهاتووەکان
- **Frontend**: Next.js 14 (App Router), React 18, TypeScript
- **Styling**: Tailwind CSS, Lucide Kurdish Icons, Vazirmatn Font
- **Maps**: OpenStreetMap, Leaflet, React-Leaflet
- **Database & Storage**: Supabase (PostgreSQL, Storage Buckets, Row Level Security)
- **Local Fallback**: Zero-Config LocalStorage Engine with Auto-Sync
